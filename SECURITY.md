# Security Policy

KARZOUN-X is experimental research software and not flight software.

## Reporting

Please avoid publishing exploit details that could affect downstream users before a fix is available. Open a minimal issue for non-sensitive defects. For sensitive security reports, use GitHub's private vulnerability reporting feature if enabled for the repository.

## Secrets

Never commit API keys, tokens, spacecraft credentials, private telemetry, proprietary mission documents, or production endpoints.

## Supported versions

Only the latest commit on the default branch is maintained during the pre-release research phase.
